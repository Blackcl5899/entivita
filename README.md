## 🎯 What Is Entivita?

Entivita is a **Minecraft mod** (a small program that adds features to Minecraft) that puts a **number and a heart icon** right above the head of every creature you look at. Instead of guessing how much health a zombie or an opponent has left, you see their exact hit points — like 14/20 or 8/40 — floating in the air.

This mod is:

- **Client-side only** → You don't need to install anything on a server. It works on any multiplayer server, including vanilla ones.
- **Lightweight** → Uses almost no performance. Your game will run as smoothly as before.
- **Fully customizable** → Choose where the health text appears, what color it is, how big it is, and when it shows.
- **Perfect for PVP** → Know exactly when to push a fight or retreat.
- **Perfect for survival** → Track wild animals, hostile mobs, and your friends' health during co-op play.

## ⚙️ How to Customize Entivita

Entivita is designed to be flexible. Here's what you can change:

| Setting | What It Does |
|---------|-------------|
| **Display Mode** | Show HP always, only when damaged, or only when looking directly at the target |
| **Text Color** | Change from white to red, green, yellow, or any custom RGB value |
| **Text Size** | Make the numbers bigger or smaller |
| **Heart Icon** | Show/hide the heart, or change its scale |
| **Position Offset** | Move the text higher/lower or side-to-side relative to the mob's head |
| **Distance Limit** | Only show health for creatures within a certain range (e.g., 10 blocks, 30 blocks) |
| **Show for Players Only** | Toggle to see only player health, not mobs |
| **Show for Mobs Only** | Toggle to see only mob health, not players |
| **Require Line of Sight** | Only show HP when you can actually see the target (no wallhack style info) |

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| **Game crashes on launch** | Make sure you installed Fabric API. Check that the Fabric Loader version matches your Minecraft version. Remove other mods temporarily. |
| **No numbers appear** | Check that the mod is in the `mods` folder as a `.jar` file, not as a ZIP. Also verify you launched using the Fabric profile, not vanilla. |
| **Numbers appear for some mobs but not others** | Some modded entities may not be supported. Also check your distance limit settings. |
| **Text is too big/small** | Open config with `H` key and adjust "Text Size". |
| **I want to uninstall** | Simply delete the `.jar` file from your `mods` folder. The mod is gone. |
| **Does it work on servers?** | Yes, it's client-side. Servers don't need to install anything. |
| **Does it work with OptiFine?** | Generally yes, but if you see conflicts, try Iris (Sodium's shader mod) instead. |

## ✨ Frequently Asked Questions

**Q: Is this a cheat or hack?**
No. It's a quality-of-life visual aid. It reads information already available in the game. Many client-side utilities do this. It doesn't give you any unfair mechanical advantage — you still need to aim and fight.

**Q: Does it affect FPS?**
No. The mod adds a tiny floating text element. It's optimized to have virtually zero impact on performance.

**Q: Does it work in Creative Mode?**
Yes, it works in all game modes.

**Q: Can I see my own health?**
Yes, you can enable that option in the config. It will show your health above your own head.

**Q: Does it work with other Fabric mods?**
Yes, as long as the other mods don't change entity rendering in incompatible ways. Standard mods like Sodium, Lithium, and Iris work fine.
